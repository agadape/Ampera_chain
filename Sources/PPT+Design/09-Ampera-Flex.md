# Slide 09 — Ampera Flex · Energy-Agnostic

> Archetype F+ — Village-typology match + comparison matrix (70%). Lead: green. Light slide.

---

## Purpose
Justify the core differentiator: Ampera is NOT a solar-only company. It adapts to what each village actually has — sun, flowing water, or biomass waste — and picks the highest-yield, lowest-cost mix. Pair hard engineering data with real human + geographic context so the jury sees this is a place-based, inclusive solution, not a one-size-fits-all product.

## Headline (H2)
### Bukan surya. Apa pun sumber desa itu.

## Eyebrow
`PILAR · FLEX`

## Body copy (text 30%, ≤55 words)
> Tiap desa punya sumber daya berbeda. Ampera Flex mencocokkan teknologi ke geografi desa — surya di kawasan kering, piko-hidro di pegunungan berair, biomassa di sentra sawit. Bukan satu ukuran. Hasilnya: CAPEX turun, yield naik, jam operasi 24/7 untuk hidro. Energi menyusul sumber daya lokal — bukan sebaliknya.
